# Calculadora en Python

## Qué hace
Programa de consola que suma, resta, multiplica y divide dos números.

## Tecnologías
- Python 3

## Cómo usarlo
1. Descarga el archivo `calculadora.py`
2. Abre una terminal en esa carpeta
3. Ejecuta: python calculadora.py
4. Ingresa dos números y elige la operación
